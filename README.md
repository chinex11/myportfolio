# Portfolio — Obasi Kalu Uka (Urbankalu)

Static site (HTML/CSS/JS). No build step. Open `index.html` to preview.

## Free hosting on GitHub Pages
1. Create a new public repo on GitHub, e.g. `portfolio` (or `chinex11.github.io` for a root address).
2. Upload everything in this folder (keep the `assets` and `projects` folders and the `.nojekyll` file).
3. Repo > Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Your site goes live at https://chinex11.github.io/portfolio/ (or https://chinex11.github.io/).

## Alternative: Cloudflare Pages / Netlify
Drag and drop this folder (or connect the repo). No build command; publish directory is the folder root.
